# Chrome 自动登录插件

一个功能强大的 Chrome 浏览器插件，支持多网站自动填充登录信息，提高登录效率。

## 功能特性

- 🔐 **安全加密存储**：使用 AES-GCM 加密算法保护账号密码
- 🌐 **多网站支持**：可管理多个网站的登录信息
- 🎯 **智能识别**：自动识别登录页面（URL 匹配 + 元素检测）
- ⚡ **自动填充**：页面加载后自动填充登录信息
- 🖱️ **手动触发**：支持手动触发填充功能
- 🔄 **自动登录**：可选自动点击登录按钮
- 🎨 **现代化界面**：简洁美观的管理界面

## 安装方法

1. 下载或克隆本项目到本地
2. 打开 Chrome 浏览器，进入扩展程序管理页面：
   - 方法1：在地址栏输入 `chrome://extensions/`
   - 方法2：点击右上角三点菜单 → 更多工具 → 扩展程序
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择项目文件夹
6. 插件安装完成！

## 使用方法

### 添加网站配置

1. 点击浏览器工具栏中的插件图标
2. 点击"添加网站"按钮
3. 填写以下信息：
   - **网站名称**：便于识别的名称（如：百度）
   - **URL 模式**：登录页面的 URL 模式，支持通配符
     - 例如：`https://www.baidu.com/login*`
     - 支持 `*`（匹配任意字符）和 `?`（匹配单个字符）
   - **用户名**：登录用户名或邮箱
   - **密码**：登录密码
   - **自动填充**：是否在页面加载时自动填充
   - **自动登录**：是否在填充后自动点击登录按钮
4. 点击"保存"

### URL 模式示例

- `https://example.com/login*` - 匹配所有以 `/login` 开头的 URL
- `https://*.example.com/login` - 匹配所有 example.com 的子域名
- `https://example.com/*/login` - 匹配中间有任意路径的登录页面

### 手动填充

如果某个页面没有自动填充，可以：
1. 打开登录页面
2. 点击插件图标
3. 点击"手动填充"按钮

### 编辑/删除配置

在插件弹窗中，每个网站配置右侧有：
- ✏️ 编辑按钮：修改网站配置
- 🗑️ 删除按钮：删除网站配置

## 项目结构

```
chrome_extension_autologin/
├── manifest.json          # 插件配置文件
├── popup/                 # 弹窗界面
│   ├── popup.html         # 界面 HTML
│   ├── popup.js           # 界面逻辑
│   └── popup.css          # 界面样式
├── content/               # 内容脚本
│   └── content.js        # 自动填充逻辑
├── background/           # 后台脚本
│   └── background.js     # 存储和消息处理
├── utils/                # 工具模块
│   ├── crypto.js         # 加密工具
│   └── siteDetector.js   # 登录页面检测
└── icons/                # 插件图标
    └── icon.svg          # SVG 图标源文件
```

## 安全说明

- 所有密码使用 AES-GCM 加密算法存储在本地
- 加密密钥基于设备特征生成，不会上传到服务器
- 数据仅存储在本地浏览器中，不会同步到云端
- 建议定期备份重要账号信息

## 注意事项

1. **图标文件**：项目中的 `icon.svg` 需要转换为 PNG 格式（16x16, 48x48, 128x128）才能正常显示。可以使用在线工具或图像处理软件转换。

2. **首次使用**：首次使用时，插件会自动生成加密密钥，请确保不要清除浏览器数据，否则需要重新配置。

3. **兼容性**：插件支持大多数常见的登录表单，但对于特殊结构的表单可能需要手动调整 URL 模式。

## 开发说明

### 技术栈

- Manifest V3
- Web Crypto API（加密）
- Chrome Storage API（存储）
- Content Scripts（页面注入）
- Service Worker（后台脚本）

### 本地开发

1. 修改代码后，在 `chrome://extensions/` 页面点击插件的"刷新"按钮
2. 重新加载测试页面以应用更改
